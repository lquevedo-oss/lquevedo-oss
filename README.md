## Cómo trabajo

Parto del problema y sus usuarios, defino prioridades, construyo e itero con asistencia de IA y reviso el resultado con pruebas y uso real. Mi aporte combina conocimiento del negocio, decisiones de producto, dirección de interfaz y validación de las herramientas.

Experiencia de proyectos con Apps Script, Google Sheets, HubSpot, Looker Studio, BigQuery, Figma, n8n, Python y React. Los repositorios indican qué se implementó, qué sigue pendiente y qué parte se adaptó para la demostración pública.

Los ejemplos laborales y comerciales publicados usan datos ficticios y excluyen cuentas, documentos, infraestructura e información privada.
